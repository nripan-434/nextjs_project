1. OVERVIEW
--------------------------------------------------------------------------------
This document details the exact architecture, code flow, and step-by-step execution
of the Real-Time Collaboration Notification system built with Socket.io.

When a developer clicks "Collaborate" on an Idea pitch card in the feed:
  1. A WebSocket event is emitted to the Node.js backend.
  2. The backend targets the specific idea owner's private Socket room ("user_<ownerId>").
  3. The idea owner instantly receives a live toast popup alert and notification badge 
     without needing to refresh their browser.


2. DEPENDENCIES
--------------------------------------------------------------------------------
- Backend : socket.io (^4.x)
- Frontend: socket.io-client (^4.x)


3. BACKEND IMPLEMENTATION DETAILS
--------------------------------------------------------------------------------
File: backend/server.ts

a) HTTP Server Wrapping & Socket.io Initialization:
   To support WebSocket connections alongside Express, Express is wrapped inside a
   standard Node.js http.Server:

   ```typescript
   import http from 'http';
   import { Server } from 'socket.io';

   const app = express();
   const server = http.createServer(app);

   const frontendOrigin = (process.env.FRONTEND_URL || 'http://localhost:3000').replace(/\/$/, '');

   export const io = new Server(server, {
     cors: {
       origin: frontendOrigin,
       credentials: true
     }
   });
   ```

b) Room Management & Real-Time Event Dispatch:
   Each logged-in user joins a private room named `user_${userId}`. When a sender
   emits `send_collaborate_request`, the server forwards it directly to `user_${ownerId}`:

   ```typescript
   io.on('connection', (socket) => {
     // Step A: Client joins their private user room upon login
     socket.on('join_user_room', (userId: string) => {
       if (userId) {
         socket.join(`user_${userId}`);
       }
     });

     // Step B: Listen for collaboration request emitted by sender
     socket.on('send_collaborate_request', (data: {
       senderId: string;
       senderName: string;
       senderAvatar?: string;
       ownerId: string;
       ideaId: string;
       ideaTitle: string;
     }) => {
       if (data.ownerId) {
         // Emit ONLY to the idea owner's private room
         io.to(`user_${data.ownerId}`).emit('new_collaborate_notification', {
           id: Date.now().toString(),
           senderId: data.senderId,
           senderName: data.senderName,
           senderAvatar: data.senderAvatar,
           ideaId: data.ideaId,
           ideaTitle: data.ideaTitle,
           timestamp: new Date().toISOString()
         });
       }
     });
   });

   // Listen on HTTP server
   server.listen(5000, () => {
       console.log('server with socket.io is running on http://localhost:5000');
   });
   ```


4. FRONTEND UTILITY SETUP
--------------------------------------------------------------------------------
File: frontend/utils/socket.ts

The client establishes a single, persistent WebSocket connection to the backend:

```typescript
import { io } from 'socket.io-client';

const BACKEND_URL = process.env.NEXT_PUBLIC_API_URL || 'http://localhost:5000';

export const socket = io(BACKEND_URL, {

```


5. FRONTEND UI & EVENT FLOW
--------------------------------------------------------------------------------
File: frontend/app/userhome/page.tsx

a) Joining Room & Listening for Notifications (Idea Owner Side):
   When the user logs in, the component emits `join_user_room` and registers a listener
   for `new_collaborate_notification`:

   ```typescript
   import { socket } from '@/utils/socket';

   const [notifications, setNotifications] = useState<any[]>([]);
   const [toastMessage, setToastMessage] = useState<string | null>(null);

   useEffect(() => {
     if (user?.id) {
       // Join private socket room
       socket.emit('join_user_room', user.id);

       // Listen for incoming notifications
       socket.on('new_collaborate_notification', (data: any) => {
         setNotifications((prev) => [data, ...prev]);
         setToastMessage(`🚀 ${data.senderName} wants to collaborate on your idea: "${data.ideaTitle}"`);
         setTimeout(() => setToastMessage(null), 6000);
       });

       return () => {
         socket.off('new_collaborate_notification');
       };
     }
   }, [user?.id]);
   ```

b) Emitting Collaboration Request (Sender Side):
   When a user clicks the "Collaborate" button on an Idea Card:

   ```typescript
   <IdeaCard
     idea={idea}
     onCollaborate={(selectedIdea) => {
       if (!user) return;
       socket.emit('send_collaborate_request', {
         senderId: user.id,
         senderName: user.username || user.email.split('@')[0],
         senderAvatar: user.avatar,
         ownerId: selectedIdea.authorId,
         ideaId: selectedIdea.id,
         ideaTitle: selectedIdea.title
       });
       setToastMessage(`✅ Collaboration request sent to ${selectedIdea.author?.username || 'Idea Owner'}!`);
       setTimeout(() => setToastMessage(null), 4000);
     }}
   />
   ```

c) Toast Popup & Sidebar Notification Badge UI:
   - Floating Toast UI (Renders at top-right):
     ```tsx
     {toastMessage && (
       <div className="fixed top-5 right-5 z-50 bg-gradient-to-r from-indigo-600 to-purple-600 text-white px-5 py-3 rounded-2xl shadow-2xl border border-indigo-400/40 text-xs font-semibold flex items-center gap-3 animate-bounce">
         <span>{toastMessage}</span>
         <button onClick={() => setToastMessage(null)} className="text-white/70 hover:text-white text-base font-bold">&times;</button>
       </div>
     )}
     ```
   - Sidebar Badge Update:
     ```tsx
     <NavItem 
       icon={BellIcon} 
       label="Notifications" 
       badge={notifications.length > 0 ? notifications.length.toString() : undefined} 
     />
     ```


6. STEP-BY-STEP EXECUTION TRACE
--------------------------------------------------------------------------------
1. User A (Collaborator) clicks "Collaborate" on User B's Idea pitch card.
2. Frontend emits `send_collaborate_request` via socket.io client.
3. Backend receives the socket message and identifies `ownerId` (User B's ID).
4. Backend targets `user_<UserB_ID>` room via `io.to(...).emit('new_collaborate_notification', data)`.
5. User B's browser instantly receives the event, triggers `setNotifications`, updates 
   the sidebar badge (+1), and pops up a live floating alert toast!
